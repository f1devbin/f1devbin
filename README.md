### Hi, I'm Max

I trained as a programmer and have worked as an electronics engineer for many years. Most of the software I write
is for myself, for problems I actually run into. When a tool turns out to be useful to other people too, I tidy it
up, write tests and documentation and publish it. And I love cats.

More about me and my projects, in seven languages: **[f1devbin.github.io](https://f1devbin.github.io/)**

#### Projects

**[Crypto Research Labs](https://github.com/f1devbin/Crypto-Research-Labs)**, an open lab where I test crypto trading
ideas and publish every result, failures included. Each idea is sealed with a hash before it is tested, fees are
always counted, and GitHub Actions re-test everything on new data.
[Dashboard and beginners' course](https://f1devbin.github.io/Crypto-Research-Labs/).

**[Telegram Bot Manager](https://github.com/f1devbin/telegram-bot-manager)**, a free page for setting up a Telegram
bot in the browser: webhooks, commands, profile, menu button and admin rights. There is no server behind it, and the
token stays in your browser. [Open it](https://f1devbin.github.io/telegram-bot-manager/).

**[My IP & Geo](https://github.com/f1devbin/my-ip-geo-plasma6)**, a KDE Plasma 6 widget: public IP and country,
local interfaces, a network scanner with port scan, diagnostics, a speed test, traffic per app and a device monitor.
No root rights, no telemetry. [Download](https://github.com/f1devbin/my-ip-geo-plasma6/releases/latest).
